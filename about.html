About:

What I’m learning, what I’ve built so far and where I want to improve.

PROFILE

I’m a student learning software development, mainly interested in backend work. I like understanding what happens after someone clicks a button: how the program handles the request, where the data goes and what the server does with it.

Python is the language I use most. So far, I’ve built a Discord moderation bot, a desktop app for Discord webhooks and a stock market simulation. They have given me different problems to work through, like checking input, handling data and working out why something behaves differently from what I expected.

I’m interested in Linux as well, including the command line, services and databases. I enjoy finding out what a tool is doing instead of treating it as magic. There’s plenty I haven’t learnt yet, and I don’t want this site to suggest otherwise.

When I get stuck, I usually narrow the problem down and test one part at a time. Documentation helps, but sometimes I still have to try things and read the error properly. I want to be able to explain the code I use, not just get something working by copying a solution.

I want to keep improving at backend development and take on bigger projects as I learn. This site shows what I’ve worked on so far. I’ll add to it as I build more.

INTERESTS

Backend

Application logic, APIs, validation, databases and data handling.

Systems

Linux, processes, services, networking basics and how software runs in practice.

Programming

Debugging, testing, readable code, reliability and learning from mistakes.

IN PRACTICE

The projects here include a Discord bot that records moderation cases and runs on Linux, a desktop app for preparing webhook requests, and a Python stock market simulation. I’ve had to solve different problems in each one, which is more useful to me than only following a tutorial.

I’m still learning. The site is meant to show what I’ve actually tried, not make me sound more experienced than I am.
